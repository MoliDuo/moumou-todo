# 哞哞清单 (moumou-todo)

Windows 桌面浮窗待办小组件（Electron）。常驻桌面、开机自启，通过托盘图标控制显示与退出。

- [`app/`](app/) — 应用源码，开发、测试、打包说明见 [app/README.md](app/README.md)
- [`project/`](project/) — 原始设计稿（Claude Design 导出的 HTML 原型，主设计为 `Floating Todo Widget.dc.html`），实现时以它为视觉参考
- [`.github/`](.github/) — 推送到 `main` 自动构建并发布 Windows 版本，见 [RELEASING.md](.github/RELEASING.md)

## 快速开始

```bash
cd app
npm install
npm start
```
